# ServiceDesk Lite

Лёгкое веб-приложение для управления заявками в IT-поддержку, разработанное на C#, ASP.NET Core Razor Pages и SQLite.

ServiceDesk Lite позволяет создавать, просматривать, искать, фильтровать и редактировать заявки. Также приложение поддерживает изменение статусов и добавление комментариев с сохранением истории обсуждения.

## Возможности

- **Управление заявками** — создание, просмотр и редактирование заявок.
- **Поиск и фильтрация** — поиск заявок и фильтрация по статусу, категории и приоритету.
- **Отслеживание статусов** — статусы «Открыта», «В работе» и «Решена».
- **Комментарии** — добавление комментариев с сохранением в базе данных.
- **Страница заявки** — просмотр подробной информации и истории комментариев.
- **Проверка данных** — обязательные поля, ограничения длины и проверка допустимых значений.
- **Постоянное хранение данных** — SQLite и Entity Framework Core для хранения заявок и комментариев.
- **Счётчики на главной странице** — отображение количества заявок по статусам.

## Запуск проекта

### Требования

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- Редактор кода, например [Visual Studio Code](https://code.visualstudio.com/)

### Инструкция по запуску

1. Клонируй репозиторий:

   ```bash
   git clone https://github.com/iseedeadpeople792/ServiceDeskLite.git
   ```

2. Перейди в папку проекта:

   ```bash
   cd ServiceDeskLite
   ```

3. Восстанови зависимости:

   ```bash
   dotnet restore
   ```

4. Примени миграции базы данных:

   ```bash
   dotnet ef database update
   ```

   Если инструмент Entity Framework Core CLI не установлен, выполни:

   ```bash
   dotnet tool install --global dotnet-ef
   ```

5. Запусти приложение:

   ```bash
   dotnet run
   ```

6. Открой локальный адрес, который появится в терминале.

## База данных

Приложение использует SQLite для постоянного хранения данных. Entity Framework Core отвечает за взаимодействие с базой данных и миграции её структуры.

Локальный файл базы данных не входит в репозиторий. Для создания структуры базы данных необходимо применить миграции.

## Структура проекта

- `Data/` — контекст базы данных.
- `Migrations/` — миграции Entity Framework Core.
- `Models/` — модели заявок и комментариев.
- `Pages/` — Razor Pages и пользовательский интерфейс.
- `Services/` — логика управления заявками и работы с данными.
- `wwwroot/` — статические файлы, включая CSS и JavaScript.
- `Program.cs` — конфигурация приложения и внедрение зависимостей.

## Статус проекта

Это учебный проект для портфолио, созданный для практики C#, ASP.NET Core, работы с базами данных и веб-разработки.

Проект демонстрирует основные функции управления заявками, но пока не является готовой промышленной системой IT-поддержки.
